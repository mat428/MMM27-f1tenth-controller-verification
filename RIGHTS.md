# Publication and reuse permissions

This package does not assign a new software or data licence on behalf of
the authors, their institutions or their funders. Before making the repository
public, the authors must confirm release rights and select appropriate terms
for their code, experiment data and manuscript. A repository without a licence
does not grant a general reuse licence merely because it is publicly readable.

The upstream F1TENTH simulator is an independently maintained dependency.
It is downloaded at a pinned commit rather than copied into this repository.
Its MIT notice is retained in provenance/F1TENTH_LICENSE.txt. Source files in
the installed upstream project retain their original notices. Those notices
do not automatically license the authors' manuscript, data or new scripts.

No publisher-formatted papers, uploaded reference PDFs, access credentials,
university logos or journal class files are included in this research-code
repository. The updated Overleaf project is supplied separately.
